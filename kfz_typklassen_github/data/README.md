# Eingabedaten (nicht im Repository)

Lege hier zwei Dateien ab:

- `typen.csv`: KBA-Bestandsdatei ohne Kopfzeile; Spalten in dieser Reihenfolge:
  HSN, Herstellername, TSN, Handelsname, Anzahl (CSV-Trennzeichen Komma).
- `kfzTypen.ams`: ZIP-Archiv mit der Datei `KfzTypen.dat`, deren Datenzeilen
  zehn Felder enthalten (HSN, TSN, Modell, Hersteller, Hubraum, LeistungKW,
  Typklasse HP/TK/VK, GueltigBis).

Die tatsächlichen Veröffentlichungsjahre, Lizenzbedingungen und Bezugsquellen
sind vor einer öffentlichen Weitergabe individuell zu ergänzen. Der Upload
enthielt das Notebook, nicht diese Rohdateien.
