# Ergebnisdateien

`modellgruppen_top15_notebook.svg` zeigt eine **redaktionell verdichtete Visualisierung gespeicherter Notebook-Ergebnisse**. Die Zahlen wurden aus der Textausgabe der ursprünglichen Analyse übernommen und nicht mit den Originaleingabedateien neu berechnet.

Beim lokalen Aufruf von `src/analyse_kfz.py` entstehen hier unter anderem:
- `hsn_auswahl.png`
- `bestand_je_typklasse.png`
- `leistung_und_typklasse.png`
- `hsn_statistik.csv`
- `gematchte_typklassen.csv`

Die großen CSV-Ausgaben werden durch `.gitignore` vom versehentlichen Upload ausgeschlossen. Vor einer Veröffentlichung von Ergebnisdaten sind Datenqualität, Quellenstand und Weitergaberechte zu prüfen.
