# Ergebnisse und Diagramme

**[Ergebnisgalerie mit allen zehn bereitgestellten Originaldiagrammen öffnen](GALERIE.md)**

Die zehn PNG-Grafiken wurden für GitHub **ohne Änderung ihrer dargestellten Zahlen und Beschriftungen** auf eine kleinere Dateigröße komprimiert. Sie stammen aus der ursprünglichen explorativen Notebook-Auswertung. Eine unabhängige erneute Berechnung anhand der originalen Rohdatensätze war nicht möglich.

`modellgruppen_top15_notebook.svg` wurde separat als kompakter Überblick aus zwischengespeicherten Notebook-Zahlen rekonstruiert, nicht mit den Originaldaten nachgerechnet.
